# Wallet Mantra --- UX Review & Product Design Feedback

## Executive Summary

**Overall Score: 91/100**

Wallet Mantra has evolved beyond a traditional expense tracker into an
**AI-powered financial companion**. The visual design is polished, the
information hierarchy is strong, and Tara creates a differentiated
experience. The highest-impact improvements now lie in UX writing
consistency, accessibility, progressive disclosure, and explainable AI.

------------------------------------------------------------------------

# 1. Initial Scan

## Core User Journey

1.  Set monthly income and recurring bills.
2.  Log daily expenses using natural language.
3.  Review AI insights and financial health.

## First-time User Tasks

-   Add monthly income
-   Add recurring bills
-   Configure budgets (optional)
-   Log first expense
-   Review Today's Insight
-   Ask Tara for more guidance

------------------------------------------------------------------------

# 2. Heuristic Review

## P1 --- Must Fix

-   Standardize terminology:
    -   Bills (instead of Fixed)
    -   Budgets (instead of Spending Caps)
    -   Insights (instead of Signals)
-   Add parser validation for natural-language expense entry.
-   Improve secondary text contrast to WCAG AA.
-   Increase touch targets for edit icons, checkboxes and notification
    icons.
-   Provide Undo after delete.
-   Explain AI decisions using **"Why am I seeing this?"**

## P2 --- Should Improve

-   Reduce Overview density with collapsible sections.
-   Add accessibility labels for charts and buttons.
-   Add swipe gestures for common actions.
-   Improve onboarding guidance.
-   Replace technical terminology with user language.

## P3 --- Nice to Have

-   Voice expense logging.
-   Adaptive AI home screen.
-   Rich micro-interactions and haptics.
-   Weekly AI financial recap.
-   Celebration moments for milestones.

------------------------------------------------------------------------

# 3. Accessibility Review

## WCAG

-   Improve placeholder contrast.
-   Ensure minimum 44×44 touch targets.
-   Add screen-reader labels.
-   Respect reduced-motion preferences.
-   Provide text summaries for charts.

------------------------------------------------------------------------

# 4. UX Writing Recommendations

Replace:

-   Log Expenses → Quick Log
-   Fixed → Bills
-   Spending Caps → Budgets
-   Category Winner → Top Spending Category
-   How Tara calculated this → Why am I seeing this?

Improve placeholders:

> Coffee 180, Uber 420, Groceries 950

Use:

> Just type naturally

## Final Recommendation

Wallet Mantra is no longer competing as an expense tracker---it is
becoming an AI financial coach. The next milestone should focus on
clarity, accessibility, trust, and reducing cognitive load rather than
adding more features. Consistent terminology, explainable AI, stronger
accessibility, and progressive disclosure will significantly elevate the
overall experience while reinforcing Wallet Mantra's premium
positioning.
